## Hey, I'm Alec

Recent computer science graduate from Farmingdale State College with a strong interest in backend development, networking, and systems programming. Currently building a DNS resolver in modern C++ and working on a self-hosted homelab. Interested in building backend applications and learning more about the networking and systems infrastructure that support them.

---

### What I'm Building

**[DnsResolver](https://github.com/alecmucz/DnsResolver)** — DNS stub resolver in C++26, built on a UDP/TCP socket abstraction layered over the BSD API.

<sub>`C++26` `BSD Sockets` `DNS` `Catch2` `ASan/UBSan`</sub>

<details>
<summary>Details</summary>

*MVP Goals:*

- Wire-format packet encoding and parsing
- TTL-aware LRU answer cache
- Catch2 test suite, ASan/UBSan builds

</details>

**Homelab** — Self-hosted infrastructure on Proxmox and UniFi across a segmented LAN.

<sub>`Proxmox` `UniFi` `Caddy` `Cloudflare` `Docker` `NFS`</sub>

<details>
<summary>Details</summary>

- Caddy reverse proxy with Cloudflare DNS-01 wildcard certificates
- Docker services behind the proxy
- NFS-backed storage and backups

</details>
